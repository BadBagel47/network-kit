# network-kit

A shared multiplayer room server and browser client for small browser games, running on Cloudflare.

- Rooms with short codes, secure share links and QR codes.
- Seats and roles (players, spectators, big screens), late join, kick and ban.
- Automatic reconnection when a phone switches networks or a tab comes back.
- One admin page for all games: on/off/until, private rooms only, emergency stop and a daily budget per game.

Each game keeps its own rules and plugs them into the room server.
