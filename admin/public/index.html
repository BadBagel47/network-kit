      Game links

      A game link lets whoever opens it create, join and start games, alone or with others, while the game or a mode takes no new players or is closed by Cloudflare limiting (not after an emergency stop). Friends invited from a room made with the link get in too, as long as the link is valid. Open it once on each device; revoke it here.

      Messages to players

      Shown in a box with a warning sound on every page of the game, within about a minute, until the player presses OK. Warnings before Cloudflare limiting closes a game are sent by themselves.
